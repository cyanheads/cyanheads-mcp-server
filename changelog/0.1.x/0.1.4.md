# 0.1.4 — 2026-05-28

## Added

- **`manifest.json`** + **`.mcpbignore`** + `bun run bundle` script restore the `.mcpb` packaging path. The `Install in Claude Desktop` badge in the README now resolves to `releases/latest/download/cyanheads-mcp-server.mcpb` and one-click-installs into Claude Desktop without manual JSON editing. `manifest.json` exposes `CATALOG_URL` and `SIMILARITY_FLOOR` as `user_config` knobs so users can override the default fleet or tighten the relevance cutoff at install time.
- **`scripts/lint-packaging.ts`** — env-var alignment linter between `manifest.json` and `server.json` (stdio package `environmentVariables[]`). Wired into `devcheck` (skips cleanly when `manifest.json` is absent).
- **`server.json` `remotes[]`** — advertises `https://cyanheads.caseyjhand.com/mcp` as a streamable-http endpoint so MCP Registry consumers can discover the hosted instance without reading the README.
- **README** — full rewrite to match the pubmed-mcp-server gold standard: centered hero with title + tool count, badge row (Version, License, Docker, MCP SDK, npm, TypeScript, Bun), one-click install badges (Claude Desktop `.mcpb`, Cursor deeplink, VS Code), hosted-endpoint callout, per-tool detail sections, project structure, and a configuration table covering every env var with its default.

## Changed

- **`server.json`** + **`package.json`** + **`manifest.json`** versions to `0.1.4`. `package.json` `files` array now includes `manifest.json` so it ships in the published tarball.

## Fixed

- **Embeddings runtime cache dir** — `@huggingface/transformers` defaults its model cache to a subpath inside its own `node_modules` install (`node_modules/@huggingface/transformers/.cache`). Containers that `bun install` as root then drop to a non-root runtime user (the production Dockerfile pattern) crash on first query with `EACCES: permission denied, mkdir`. `src/services/catalog/embeddings-runtime.ts` now sets `env.cacheDir` at import time to `HF_HOME` / `TRANSFORMERS_CACHE` if set, otherwise a per-OS `tmpdir/cyanheads-mcp-server/hf-cache` fallback that's always writable.
