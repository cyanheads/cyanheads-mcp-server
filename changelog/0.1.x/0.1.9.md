# 0.1.9 — 2026-05-30

## Changed

- **`cyanheads_search` enrichment adoption.** Query echo, true match total, and empty-result guidance now surface in a typed `enrichment` block that reaches both the `structuredContent` JSON and the `content[]` markdown trailer. Both channels carry the same data; clients that read either surface now see the context.
- **`structuredContent` key renames.** `totalMatched` → `totalCount` (now in `enrichment`); `query` → `effectiveQuery` (now in `enrichment`). Values and presence semantics are unchanged — keys moved out of the domain return and into the enrichment block.
- **`@cyanheads/mcp-ts-core` `^0.9.11` → `^0.9.16`.** Framework adoption: `ctx.enrich` API, `getEnrichment` test helper, enrichment contract on `tool()`, plus dev-dep bumps (`@biomejs/biome`, `@types/node`, `tsc-alias`, `tsx`, `typescript ^6.0.3`, `vitest`).
