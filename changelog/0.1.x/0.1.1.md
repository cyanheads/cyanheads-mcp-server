# 0.1.1 — 2026-05-28

First substantive release. The scaffold tag (`v0.1.0`) carried no functionality; this release lands the full fleet discovery surface.

## Added

- **`cyanheads_search`** — semantic search over fleet tools and servers. Embeds the query at runtime with [`Snowflake/snowflake-arctic-embed-m-v1.5`](https://huggingface.co/Snowflake/snowflake-arctic-embed-m-v1.5), dot-products against L2-normalized 256-dim Matryoshka-truncated document vectors, filters by category and similarity floor, returns ranked matches. Auth scope: `tool:cyanheads_search:read`.
- **`cyanheads_describe`** — returns description, hosted connection URL, and per-client install snippets (Claude Desktop, Claude Code, Cursor, Cline) for any named tool or server. Auto-detects kind from name format (underscores → tool, hyphens → server). Auth scope: `tool:cyanheads_describe:read`.
- **`CatalogService`** — in-memory packed `Float32Array` vector index, atomic-swap refresh on every `fleet.json` `generatedAt` change. Polls hourly by default.
- **`TransformersEmbeddingsRuntime`** — wraps `@huggingface/transformers`'s `feature-extraction` pipeline. Loads the model once at startup and reuses it for every query.
- **`RemoteJsonCatalogProvider`** — fetches and Zod-validates the v2 `fleet.json` payload from `CATALOG_URL` (default `https://caseyjhand.com/fleet.json`). Refuses to load on `embeddingModel` mismatch.
- **Env vars:** `CATALOG_URL`, `CATALOG_FETCH_TIMEOUT_MS`, `CATALOG_REFRESH_SECONDS`, `EMBEDDING_MODEL_ID`, `SIMILARITY_FLOOR`.
- **Marketing-style README** positioning the hosted endpoint (`https://cyanheads.caseyjhand.com/mcp`) as the product, with per-client install blocks and a category table for the fleet.

## Changed

- **npm name** scoped to `@cyanheads/cyanheads-mcp-server`.
- **`mcpName`** added (`io.github.cyanheads/cyanheads-mcp-server`) for MCP Registry resolution.
- **`server.json`** declares all server-specific env vars on both stdio and HTTP package entries.

## Removed

- **Echo scaffold** — five definition files and three tests carried over from `bunx init` removed once real definitions landed.
- **`manifest.json` / `.mcpbignore` / `.codex-plugin/` / `.claude-plugin/`** — the `.mcpb` bundle and plugin marketplace metadata assumed an npx-stdio install path that conflicts with the hosted-endpoint positioning. The corresponding `bundle` and `lint:packaging` scripts went with them.
