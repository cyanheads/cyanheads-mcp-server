# 0.1.3 — 2026-05-28

## Fixed

- **`Dockerfile`** build stage now runs `bun scripts/build.ts` instead of `bun run build`. The previous form went through `tsx`, which trips a CJS resolver issue inside `oven/bun:1.3` containers (`Cannot find module './cjs/index.cjs'`) on both `linux/amd64` and `linux/arm64`. Required for the multi-arch GHCR image to build at all.
