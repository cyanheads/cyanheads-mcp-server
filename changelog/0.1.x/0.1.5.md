# 0.1.5 — 2026-05-28

## Changed

- **`cyanheads_describe` install snippets** — full rewrite. The 0.1.4 builders emitted `type: "sse"` and `--transport sse`, which the hosted endpoint never actually spoke (it runs Streamable HTTP). Snippets pasted into client configs would either fail outright or fall back to legacy transport paths. New formats are derived from working reference commands and verified against `https://cyanheads.caseyjhand.com/mcp`:

  | Client | Format |
  |:--|:--|
  | `claude-code` | `claude mcp add --transport http <name> <url>` |
  | `codex` | `codex mcp add <name> --url <url>` |
  | `cursor` | `mcpServers.<name>.{url}` (no `type` field — Cursor reads HTTP servers from URL alone) |
  | `curl` | `initialize` POST with `MCP-Protocol-Version: 2025-11-25` for connectivity testing |
  | `gemini` | `gemini mcp add --transport http <name> <url>` |
  | `streamable-http` | `mcpServers.<name>.{type:"http", url}` — generic shape consumed by Claude Desktop, Cline, and `mcp-remote` |

- **`ClientId` union** — `'claude-desktop' | 'claude-code' | 'cursor' | 'cline'` → `'claude-code' | 'codex' | 'cursor' | 'curl' | 'gemini' | 'streamable-http'`. Claude Desktop and Cline both consume the generic `streamable-http` format, so a single `streamable-http` entry replaces the two client-specific ones. `codex`, `gemini`, and `curl` are new.

## Breaking

- **`cyanheads_describe` `client` parameter values changed.** Callers that pin `client: 'claude-desktop'` or `client: 'cline'` will get a Zod validation error. Use `client: 'streamable-http'` instead — same JSON shape, with the correct `type: "http"` field. `client: 'claude-code'` and `client: 'cursor'` still work but emit the corrected payload.
- **`InstallSnippet.client` values changed.** Consumers that switch on the client string need to map the old IDs to the new ones (or read every snippet and let payload-shape detection drive UI rendering).

## Fixed

- **Stale doc references to SSE transport** — `src/services/catalog/types.ts` (`endpoint` JSDoc), `src/mcp-server/tools/definitions/describe.tool.ts` (output field describe text), `docs/design.md` (supported-clients table + snippet examples + `ClientId` example). All now say Streamable HTTP.
