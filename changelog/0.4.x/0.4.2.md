# 0.4.2 — 2026-09-19

## Changed

- **`@cyanheads/mcp-ts-core` `^0.12.3` → `^0.13.6`** adopts `createApp({ sessionMode, teardown })`, moves the framework's skill tree to `framework-skills/`, and tightens the tool-argument rejection envelope.
- **`MCP_SESSION_MODE` defaults to `stateless`** (#18) via `createApp({ sessionMode: 'stateless' })` in `src/index.ts`, so the container, `bunx`, and a source run all agree — previously only the Docker image defaulted to it.
- **Tool argument rejections classify as `InvalidParams` (`-32602`)**, not `ValidationError` (`-32007`), and `content[]` now closes with a schema-derived `Recovery:` hint and a `(reason … )` trailer.
- **The server card publishes the resolved session mode** under the namespaced `_meta` key `io.github.cyanheads.mcp-ts-core/sessionMode`.

## Fixed

- **`catalog_empty` now advertises `retryable: true` on the wire** (#19) — both throw sites (`CatalogService._assertInitialized`, `getCatalogService`) set it, so the `content[]` trailer agrees with what both tools declare in `errors[]`.
