# 0.4.1 — 2026-08-21

## Added

- **Test lanes** add smoke coverage for every definition, framework contract integration tests, property-based fuzzing, and Istanbul coverage reporting.
- **Repository guidance** adds contribution and conduct documents, plus a dedicated `security@caseyjhand.com` reporting contact with credential-redaction guidance.

## Changed

- **`@cyanheads/mcp-ts-core` ^0.11.0 → ^0.12.3** migrates catalog failures to framework error factories and remote catalog loading to `fetchWithTimeout`, including whole-exchange timeouts and redacted network errors.
- **MCP protocol metadata** now targets `@modelcontextprotocol/server` 2.0.0 and protocol revision `2026-07-28`; MCPB configuration exposes every catalog runtime setting.
- **Container builds** use Bun 1.4.0 for both stages, build through the package script, and omit optional peer tiers from the production install.
- **Framework skills** document multi-round-trip input, 2026-era caching and notifications, schema/linter additions, parser budgets, telemetry shutdown, and updated testing patterns.
- **Build tooling** type-checks source and tests together while emitting source only; the directory tree generator now honors directory-only ignore patterns.

## Fixed

- **`bun audit` classification** recognizes Bun 1.4 npm-spec package headers and `>` dependency paths so transitive advisories remain correctly classified.
- **Catalog response-body timeouts** preserve the framework's typed `Timeout` error instead of being relabeled as `InternalError` during JSON parsing.

- `@types/node` ^26.1.1 → ^26.2.0
- `tsc-alias` ^1.9.1 → ^1.9.2
- `vitest` ^4.1.10 → ^4.1.11
