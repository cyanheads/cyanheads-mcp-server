# 0.4.5 — 2026-10-24

## Changed

- **Catalog timer configuration** validates fetch timeouts as integer milliseconds from `1` to `2147483647` and refresh intervals from `0` to `2147483.647` seconds at startup; fractional refresh seconds remain accepted.
- **Development tooling** synchronizes framework skills and devcheck with `@cyanheads/mcp-ts-core` 0.13.16; Docker images use Bun `1.4.3 → 1.4.4`.

## Fixed

- **Claude Desktop MCPB** uses bundled ONNX WebAssembly inference and a writable filesystem model cache, removing host-specific native dependencies from the bundle. npm and Docker retain native CPU inference. ([#31](https://github.com/cyanheads/cyanheads-mcp-server/issues/31))
- **Optional enum inputs** treat exactly `""` as omitted for describe `kind`/`client` and search `category`, preserving advertised enum values and optional status. ([#33](https://github.com/cyanheads/cyanheads-mcp-server/issues/33))
- **`cyanheads_describe_entry` examples** name `earthquake_search_events`, an entry available in the catalog. ([#34](https://github.com/cyanheads/cyanheads-mcp-server/issues/34))
