# 0.5.0 — 2026-10-28

## Added

- Publish the `cyanheads-guide` agent skill as the MCP resource `skill://cyanheads-guide/SKILL.md`, shipped in the npm package, Docker image, and `.mcpb`.
- Root Agent Plugins `plugin.json` and `mcp.json` manifests.

## Changed

- The `requiredEnvVars` descriptions on `cyanheads_describe_entry` say they list the variables a server's manifest marks required, not every key its tools need; the `category` description on `cyanheads_search_catalog` warns that a wrong category drops the matching server.

## Dependencies

- mcp-ts-core ^0.13.16 → ^0.13.18: the HTTP transport no longer retains ~71 KiB per request, which grew the heap under sustained traffic (0.13.17); enrichment trailer echo values render as code spans in `content[]` (0.13.18); MCP SDK 2.3.1 → 2.4.0 (0.13.17).
- @biomejs/biome ^2.6.2 → ^2.6.3, ignore ^7.0.13 → ^7.0.14, tsc-alias ^1.9.8 → ^1.9.9; @huggingface/transformers stays at 4.3.1 (the portable bundle's ONNX adapter hard-pins it).
