# 0.2.0 — 2026-05-30

## Added

- **`cyanheads_search` servers roll-up** (scope `tools`). The response now includes a `servers` array built from the full match set before the limit slice — each entry carries `name`, `brief`, `category`, `matchedTools` (count of this server's tools in the match set), and `topScore` (best per-tool cosine). Ordered by `topScore` desc (name-tiebroken), capped at 10. `serversTotal` surfaces the true distinct-server count when the cap fires. Absent for scope `servers`. ([#4](https://github.com/cyanheads/cyanheads-mcp-server/issues/4))

## Changed

- **`cyanheads_search` zero-match path.** Returns `{ results: [], scope }` with enrichment populated (`effectiveQuery`, `totalCount: 0`, recovery `notice`) instead of throwing `no_results`. The `no_results` reason is removed from the tool's `errors[]` contract. Aligns the zero-match path with the rest of the fleet's search tools — agents no longer take an error round-trip on a valid empty query. ([#3](https://github.com/cyanheads/cyanheads-mcp-server/issues/3))

## Fixed

- **`.mcpbignore` directory excludes anchored to repo root.** Bare directory names (`src/`, `tests/`, `scripts/`, `skills/`, `docs/`, `coverage/`, `changelog/`, `announcements/`, `schemas/`) were unanchored and recursively matched inside `node_modules/`, stripping `@opentelemetry/api/build/src/` from the bundle (bundled server crashed on load). Prefixed with `/` to anchor to root. ([#2](https://github.com/cyanheads/cyanheads-mcp-server/issues/2))
