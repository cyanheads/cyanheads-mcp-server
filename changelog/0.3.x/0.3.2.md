# 0.3.2 — 2026-06-04

## Added

- **`cyanheads_describe` (server branch)** now returns a `tools` array alongside `toolCount` — each entry carries the tool's `name` and `description`, populated from `serverEntry.tools`. An agent learns a server's full tool surface from a single call without a second lookup. Resolves [#6](https://github.com/cyanheads/cyanheads-mcp-server/issues/6).
- **`format()`** renders a `## Tools` section (bullet list of `` `name` — description `` entries) after the Description block so both `structuredContent` and `content[]` consumers see the tool inventory.
