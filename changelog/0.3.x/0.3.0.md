# 0.3.0 — 2026-06-02

## Added

- **`cyanheads_describe`** returns local (stdio) install snippets via `npx -y <pkg>` for every published server: `claude-code`, `codex`, `cursor`, `gemini`, and a generic Claude Desktop / Cline config ([#5](https://github.com/cyanheads/cyanheads-mcp-server/issues/5)).
- **`InstallSnippet.transport`** field (`"stdio" | "http"`) — callers can filter or branch on transport without string inspection.
- **`CatalogRecord.requiredEnvVars`** optional field — surfaces required env vars and scaffolds them as empty-valued `env` keys in local JSON configs.

## Changed

- **`cyanheads_describe`** output now groups snippets into `## Local install (stdio)` and `## Remote install (HTTP)` sections when both apply; HTTP-only when no `endpoint` is present on the record.
- **`CatalogRecord.endpoint`** is now optional (was required) — forward-compatible with local-only servers that have no hosted HTTP endpoint.
- **`curl` probe** is emitted only for servers with a hosted endpoint; dropped for endpoint-less records.
- **MCP server config key** in README install examples renamed from `cyanheads` to `cyanheads-mcp-server`.
